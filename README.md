# MyBudget

Advanced Personal Finance Tracker Web App

## Features

- Add Expenses
- Edit Expenses
- Delete Expenses
- Monthly Budget
- Search Expenses
- Category Filter
- Doughnut Chart
- Dark Mode
- CSV Export
- LocalStorage
- Responsive Design
- Glassmorphism UI
- Smooth Animations

## Technologies

- HTML5
- CSS3
- JavaScript
- Chart.js

## Run Project

1. Open in VS Code
2. Install Live Server
3. Right Click index.html
4. Open With Live Server
